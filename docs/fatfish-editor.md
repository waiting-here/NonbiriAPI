# Fat Fish level editor

Open **Limited-time activities → Fat Fish → Levels and versions** in the administrator station. Edit a draft, playtest it, then select the resulting version under **Periods and nodes**. Playtesting saves and checks the captured draft automatically. Publishing a version does not open a period.

The status beside Save explains missing titles, unplaced legacy fish and invalid shapes. Select an issue to find its object or field. Technical error details remain available in a disclosure. Geometry previews must be corrected or cancelled before saving.

On desktop, creation tools appear on the left, the canvas in the middle and selected-object properties on the right. New shapes appear near the visible center. Add Fish enters continuous placement; a translucent fish and direction arrow show the next placement. Red previews identify collisions. Press Escape to stop.

- Select a shape before editing its vertices, outer contour or holes. In vertex mode, Delete removes only the selected vertex.
- Use the eight direction buttons or clockwise degrees; 0° points right. Numeric edits become one undo step when you leave the field or press Enter.
- Ctrl + wheel zooms around the pointer; Space + drag pans. Fit screen restores the full view.
- Arrow keys move the selection by 8 pixels with grid snapping enabled, or 5 pixels without it. Hold Shift for 1-pixel adjustments.
- File contains import, export, examples, optional server checks and deletion. Deleting a library entry does not remove its published versions.

On phones, use one finger to select objects or pan empty space, and two fingers to zoom. Properties and playtesting remain available. Use a computer for contour and vertex editing. Secondary actions are under More.

Exported level files and older 0.6 files can be imported. Older rules remain identifiable and are converted only when requested. Rules, level formats, verification and game accounting are unchanged.
