# Claude chiffon costume study

Archived layer study for the adopted adult Christmas Claude costume. The old
velvet dress is retained as legacy-velvet.webp for comparison. The card catalog
now uses the sheer gown with its complete layered motion renderer.

The body and garment were generated with OpenAI's built-in image generation
tool on 2026-11-13, from the project's retained Claude artwork. The body wears
opaque matching underwear. The garment-only source contains no anatomy or
underwear; its fabric alpha is calibrated separately from the golden stitching.
The adopted underwear palette was softened to opaque dusty rose on 2026-11-13.
Only registered fabric pixels take the generated color refinement; the original
skin, gold embroidery, pose and outer gown are retained.
The front occlusion layer retains source pixels for the hands, book and selected
hair. All four WebP files share a native 1024 × 1536 canvas.

This historical preview animates only the independent fabric texture. The main
five-card preview shows the adopted SSR motion, including eyes and hair. Prompts,
source PNGs, rejected attempts and registration/export scripts are retained in
the local `christmas-v1.3.12/claude-layer-study` authoring directory.

These study assets follow the project's existing artwork license. This directory
is imported only by the local gacha preview; registered production derivatives
are exported separately under public/assets/gacha.
