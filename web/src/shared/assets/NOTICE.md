# Local visual assets

`nonbiri-mark.svg`, `state-empty.svg`, `state-error.svg`, and
`state-maintenance.svg`, together
with the inline SVG paths in `web/src/shared/components/Icon.tsx`, are
original, project-created visual assets for NonbiriAPI. They contain no
third-party artwork, fonts, or runtime network dependency and are distributed
under the repository's AGPL-3.0 license. The files are bundled by Vite and may
be used offline.

Configured site logos remain operator-supplied public HTTPS URLs and are
loaded with anonymous image requests; they are not part of this asset set.
