The picture-book cover and four waiting frames are original generated fan illustrations of Miyauchi Renge from *Non Non Biyori*, commissioned for this project. They depict the character drawing a simple picture in a rural classroom. No official illustration or extracted animation frame was used as an input or redistributed.

The cover and first waiting frame share the same image. The four 1280×720 WebP frames form a slow eight-second loop; the application also supports a static presentation and pausing. These files contain no external script, font or network reference.
